Small pictures for the dropdown lists (shown before the description of each item)
------------------------------------------------------------------------------------
Folder                 Used for                              File names
assets/icons/a3/       a3 (type of pressure change)          0.png ... 8.png and slash.png ("/")
assets/icons/ww/       ww (present weather)                  00.png ... 99.png
assets/icons/past/     W1 and W2 (past weather)              0.png ... 9.png

Size   : 96 x 96 pixels, PNG with a transparent background (the app shows it about 28 dp wide, a little taller than the text).
Colour : use a colour that is readable on a light and on a dark background (for example mid blue #1565C0).
A missing file is simply skipped (the item then shows only its text). After adding pictures, rebuild the app.
The nine a3 pictures that come with the app are only simple drawings of the pressure curve; replace them with your own.
